# plotmark.ae

Website for Plotmark Real Estate L.L.C, a boutique real estate brokerage in Dubai.

- `index.html` — the whole website (one self-contained page, brand: Plotmark Brand Book).
- `.gitlab-ci.yml` — publishes the site with GitLab Pages on every commit to the default branch.

To update the site, change `index.html` and commit. GitLab Pages republishes it in a minute or two.
